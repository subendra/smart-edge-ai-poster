Missing information: Missing or misaligned labels can hide product identity, traceability and safety information.
Human limitations: Repetitive manual inspection can vary with fatigue, reduced attention and inconsistent judgement.
Rigid automation: Rule-based vision can become unreliable when lighting, bottle position or background changes.

Local inspection by default

YOLO11n is deployed using ncnn on Raspberry Pi 4. Images are processed locally to identify present, missing or misaligned labels, reducing dependence on cloud processing.

Commercial: Supports more consistent automated quality inspection and reduces dependence on continuous manual checking.
Social & Safety: Helps reduce the risk of products with missing or misaligned labels reaching customers.
Environmental & Operational: Selective offloading avoids sending every image to the cloud and can reduce unnecessary data transmission and cloud-processing activity.

Hardware

  • Raspberry Pi 4: performs local processing and controls adaptive offloading.
  • CSI camera: captures images for inspection.
  • Cloud service: processes images when inference is offloaded.

AI & software

  • YOLO11n: detects three label conditions.
  • ncnn: enables optimised inference on Raspberry Pi.
  • Flask Framework: provides the web interface for displaying inspection results and system status.

Communication & control

  • MQTT QoS 0: exchanges offloading requests and detection results.
  • Base64 JPEG/JSON: JPEG images are Base64-encoded with JSON messages for transmission.
  • Adaptive rule: offloads when CPU utilisation remains at or above 90% for 60 seconds and returns to local inference when CPU stays at or below 65% for 20 seconds.
  • TLS and authentication: protect the communication channel between edge and cloud.
